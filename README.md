### Adventure Works Sales Analysis

## Project Overview

This project focuses on analyzing Adventure Works sales data using SQL (MySQL), Microsoft Excel, Power BI, and Tableau. The goal is to explore sales performance, identify business trends, and generate meaningful insights through data analysis and interactive dashboards.

## 💻 Tools & Technologies

- **SQL (MySQL):** Joins, Subqueries, Aggregate Functions, Date Functions, Data Analysis
- **Microsoft Excel:** Data Cleaning, Pivot Tables, Data Analysis, Dashboards
- **Power BI:** Interactive Dashboards, KPI Reports, Data Visualization
- **Tableau:** Interactive Dashboards, Sales Analysis, Data Visualization

## 🚀 Featured Project

### Adventure Works Sales Analysis

A data analytics project focused on analyzing sales data to understand business performance, identify sales trends, and evaluate profitability.

**Key Highlights:**
- Combined and transformed sales datasets using SQL.
- Joined sales data with customer and product information.
- Calculated Sales Amount, Production Cost, and Profit.
- Performed Year-wise, Month-wise, and Quarter-wise sales analysis.
- Created dashboards using Excel, Power BI, and Tableau.

**Tools Used:** MySQL, Microsoft Excel, Power BI, Tableau.
